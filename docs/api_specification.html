Group 1 — Authentication

3 Endpoints
01 POST /auth/login Authenticate user and return session
Authenticates the user and returns the JWT token along with full user profile including location scope, navigation access, and equipment module access — all in a single call.
Critical: nav_access and equipment_modules must be included here. This eliminates two extra API calls that the frontend previously made after login.
Request Body
{
  "username": "inspector_john",
  "password": "secret123"
}
Response
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": 42,
    "name": "John Doe",
    "username": "inspector_john",
    "email": "john@acme.com",
    "role": "inspector",
    "status": "active",

    // Company scope
    "company_id": 5,
    "company_name": "Acme Corp",

    // Location scope — narrowest level wins
    "branch_id": 2,
    "branch_name": "North Branch",
    "building_id": 3,
    "building_name": "Building A",
    "floor_id": 1,
    "floor_name": "Floor 1",
    "zone_id": null,
    "zone_name": null,
    "department_id": null,
    "department_name": null,

    // Hierarchy
    "shift_id": 1,
    "supervisor_id": 10,
    "supervisor_name": "Jane Supervisor",
    "agm_id": 7,
    "agm_name": "Bob AGM",

    // Pages this user can access
    "nav_access": [
      "overview",
      "reports",
      "fire_extinguisher",
      "smoke_detector",
      "emergency_light"
    ],

    // Equipment modules this user can see
    "equipment_modules": [
      {
        "module_id": 30,
        "module_code": "fire_extinguisher",
        "module_name": "Fire Extinguishers",
        "access_level": "inspect"
      },
      {
        "module_id": 36,
        "module_code": "smoke_detector",
        "module_name": "Smoke Detectors",
        "access_level": "inspect"
      },
      {
        "module_id": 38,
        "module_code": "emergency_light",
        "module_name": "Emergency Lighting",
        "access_level": "view"
      }
    ]
  }
}
access_level Values
ValueWhat the user can do
viewRead-only. Can see equipment list and status.
inspectCan perform and submit inspections.
manageCan edit equipment details and close alerts.
adminFull access including deletion and config.
02 GET /auth/me Restore session on page refresh
Called automatically on every page reload. Must return the exact same user object shape as /auth/login so the dashboard can restore state without re-login.
Response
{
  "user": {
    // Exact same shape as login response user object
    "id": 42,
    "name": "John Doe",
    "role": "inspector",
    "company_id": 5,
    "branch_id": 2,
    "building_id": 3,
    "floor_id": 1,
    "zone_id": null,
    "department_id": null,
    "nav_access": ["overview", "reports", "fire_extinguisher"],
    "equipment_modules": [ /* same array as login */ ]
  }
}
03 POST /auth/logout Invalidate session token
Response
{ "success": true }

Group 3 — Equipment

2 Endpoints

⚠️ Backend Location Filter Rule — applies to ALL data endpoints

superadminNo filter → returns equipment across all companies
adminWHERE company_id = user.company_id
agm / supervisor
inspector / user WHERE company_id = user.company_id
AND (branch_id = user.branch_id OR user.branch_id IS NULL)
AND (building_id = user.building_id OR user.building_id IS NULL)
AND (floor_id = user.floor_id OR user.floor_id IS NULL)
AND (zone_id = user.zone_id OR user.zone_id IS NULL)
AND (department_id = user.department_id OR user.department_id IS NULL)

The backend must read location scope from the authenticated user's DB record — never trust location params sent by the client.
